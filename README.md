# 观易 · 易经学习书房

以当前项目的《傅佩荣解读易经.pdf》为底本的易经学习网页。支持本地打开或 GitHub Pages 托管，无构建步骤，无在线接口、CDN、账号或运行时第三方依赖。

## 在线访问与发布

在线地址：[观易](https://moyuhama.github.io/guanyi/)。

GitHub 仓库为 `moyuhama/guanyi`。在仓库的 Settings → Pages 中选择 Deploy from a branch，发布分支为 `main`，目录为 `/(root)`。根目录的 `.nojekyll` 使 HTML、CSS、JavaScript、PDF 和原页图片按静态文件发布，不需要安装依赖或运行 Python。

更新后提交并推送到 `main`，GitHub Pages 会自动重新发布。`output/` 中的开发截图不上传。书籍 PDF、提取文字及原页图片随网站提供，书籍内容的权利归相应权利人所有。

上线网址与本地网址使用独立的浏览器存储。迁移签录、笔记等记录时，先在旧网址的「我的笔记」导出备份，再到新网址导入。手机和电脑之间不会自动同步。

## 打开网页

macOS 双击 `启动观易.command`。终端窗口运行期间，可访问 http://127.0.0.1:8765 。按 Ctrl+C 停止。

也可以在项目目录执行：

```sh
python3 server.py --open
```

如果端口已被占用，用 `python3 server.py --port 8766 --open`。服务器只监听本机，不向局域网开放。

也可直接用浏览器打开 `index.html`。PDF 打开与本地文件存储行为因浏览器而异，推荐使用本地服务器，并固定使用同一地址、端口和浏览器。

## 功能

- 返回导航：顶部固定「返回」按钮，长文滚动时仍可操作；优先回到进入当前页面前的站内页面，同卦爻辞切换与原书翻页不重复计作一层。直接打开内页时返回上一级，支持刷新和浏览器原生前进／后退。旁边的当前位置可点击返回所属栏目。

- 每日一签：首页点击抽签，从全部 64 卦中等概率随机抽取，展示卦象、卦辞、白话和书中解读节选。当天刷新保留最近一次结果，跨日后等待重新抽取；可再次抽签，也可能抽到同一卦。
- 起卦与解卦：从侧栏进入。可填写问题，用三枚虚拟钱币逐次起六爻（钱币抛起、翻转落下，再逐爻成形；支持依次演示六爻、撤回最后一爻），或选择已有本卦、勾选动爻。并排展示本卦和变卦，标红变化位置，说明选文理由，展示对应原文、书中白话、可展开的傅佩荣解读与原书链接。带有需卦九五变泰卦的免保存学习示例。
- 我的卦记：打开解读时自动记录问题与六爻；感悟输入后自动保存，可回看历史记录。起卦草稿支持刷新续接，问题、草稿与卦记随学习备份导出、合并导入。
- 每日签的上下卦导读：抽签结果同时显示上卦、下卦和对应口诀，点击可直接进入该三爻卦的互动学习，再回到原书阅读。
- 首页布局：以每日抽签和本签解读为主，底部仅保留一行最近签录与「我的签录」入口；动手学易、解卦、入门和笔记从主导航进入。
- 我的签录：自动保留最近 180 次结果，可回看、继续读卦、收藏及记下感悟，支持随学习备份导出与合并导入。
- 动手学易：学习地图串起「口诀认图 → 翻卡自测 → 动手翻爻」。先学乾、坤、离、坎，再展开八卦；口诀以红色标出关键爻，并附拼音、自然意象和成对记法。翻卡自测支持四卦、全八卦与待复习范围，熟悉度由用户自行标记；三爻工具可实时翻转并记录已经看到的八卦。
- 情境里读易：四段生活情境旅程，按「入境 → 观象 → 会意」展开。选择得到针对性反馈，动手观察乾卦爻位、需卦上下卦、泰否交换和坤变复，再对照原书、留下感悟。自动保存所在步骤与感悟，可中途离开、刷新后继续；感悟也汇集到「我的笔记」中的探索手记。
- 卦象实验室：自由翻动六爻，实时查到全部 64 卦中的对应卦象、卦辞、白话及原书页码，支持换起点、撤销与重置。
- 六十四卦：依原书卦序整理；卦名、序号、上卦、收藏与已读筛选。
- 分层阅读：原文、白话、书中解读、对照阅读；目录跳转、字号调整、PDF 页码引用。
- 卦图对照：阅读时常驻六爻图，标清阴阳、爻名、上下卦与自然意象。点一爻跳到对应爻辞，滚动正文时自动高亮当前爻；每一节也有图文对照卡。手机保留紧凑卦图，可展开选爻。
- 原页图文：阅读页内可打开对应 PDF 页面的离线高清图，查看原书的互卦、变卦等图示，翻页或放大后关闭仍回到阅读位置。
- 全文检索：搜索前言、六十四卦和系辞上下、说卦、序卦、杂卦，显示匹配片段。结果在当前标签页显示，搜索框旁的「取消」或 Esc 可清空搜索并返回搜索前的页面；尚未提交时只清空输入。连续更换关键词后也能一次退出搜索。
- 易学入门：阴阳爻、八卦意象、交互式上下卦组合。
- 温故知新：八卦识图练习、即时反馈和本地最高成绩。
- 笔记与收藏：浏览器本地保存，JSON 导出和合并导入。
- 原书阅读：完整 212 页整理文本、原页高清图及 PDF 独立打开。

## 数据与来源

浏览器的 localStorage 保存起卦草稿、卦记与感悟、签录、八卦识记与复习、已探索的三爻卦、探索进度与感悟、笔记、收藏、已读进度、阅读位置和练习成绩，不会上传。清除浏览器数据、换浏览器、切换文件模式或更换网址/端口会使用不同存储空间。可从「我的笔记」导出学习备份，导入会合并签录、已读、收藏、阅读日期与最高成绩，同一卦的笔记保留更新时间更晚的一份。探索记录按旅程合并，保留已发现的线索与完成状态，选择、感悟及所在步骤以较新版本为准；兼容没有探索字段的旧备份。八卦识记按每个卦的更新时间合并，已看到的卦象取并集；导入旧备份不会清空新增的学习记录。卦记按记录 ID 合并，同一记录保留较新的感悟；草稿采用更新时间较新的版本。

`assets/book-data.js` 和 `assets/pages-data.js` 由原 PDF 提取，包含 64 卦和全书 212 页文字。原文件有错别字、排版残留及批注；整理文本保留其用字，非校勘定本。图像不包含在文字提取中，可通过「查看原页」浏览离线页面图，也可打开 PDF 对应页。卦名导航使用「姤」等规范标题，正文保留 PDF 用字。

修改 PDF 后可重新运行提取脚本（仅此步骤需要 Python 包 `pypdf`）：

```sh
python3 -m pip install pypdf
python3 scripts/extract_pdf.py
```

探索中的生活情境、反馈、总结和行动问题为本站编写的学习引导，并非原书译文。标注为经传原文、书中白话的文字从本地提取数据读取，附对应原书链接。翻爻实验用来观察结构变化。

PDF 为用户提供的本地资料，保留在原位置；本项目未发布到网络。

## 文件

- `index.html`、`styles.css`、`app.js`：网站结构、样式、交互。
- `navigation.js`、`navigation.css`：站内返回历史、可点击位置导航和固定顶栏。
- `typography.css`：屏幕阅读排版，使用系统黑体、深色文字，正文 17–20 像素，辅助文字至少 14 像素；原书阅读字号可调为 18–26 像素。
- `daily-draw.js`：随机抽签、日期和签录管理；`node scripts/check-daily-draw.cjs` 可验证持久化规则。
- `interpret.js`、`interpret.css`：三钱起卦、手动录卦、本变卦对照、选文与卦记；`node scripts/check-interpret.cjs` 核验全部 4,096 种本卦／动爻组合、0–6 条动爻选文与书中索引、三钱概率、草稿与备份兼容；`node scripts/check-casting-motion.cjs` 核验动画防重入、逐爻呈现、途中刷新与离页、跨页草稿变化和减少动态效果。
- `learning.js`、`learning.css`：学习地图、八卦口诀卡、翻卡自测与三爻互动。`node scripts/check-learning.cjs` 核验口诀与原书卦形、全部 24 种翻爻操作、复习筛选和备份合并。
- `explore.js`、`explore.css`：情境探索、卦象实验室与探索记录管理；`node scripts/check-explore.cjs` 验证所有卦象变化、来源索引及备份兼容。
- `reader-guide.js`、`reader-guide.css`：卦图与爻辞联动、章节定位和原页图文弹窗；`node scripts/check-reader-guide.cjs` 核验 64 卦的 384 条爻辞链接、阴阳位置及文言重复章节的映射。
- `assets/`：离线阅读数据、图标和 212 页原书 WebP 预览。
- `server.py`、`启动观易.command`：本地启动入口。
- `scripts/extract_pdf.py`：可复现的 PDF 内容提取与章节完整性检查。

原页预览可使用 `scripts/render_pages.py` 重新生成（需要 `pypdfium2` 和 `Pillow`）。网页运行本身不需要这些包。

八卦取象歌采用传统口诀，提供外部出处链接；卡片说明和互动引导为本站编写，卦形与自然意象使用项目数据。网站借鉴逐步学习与每日读卦的交互思路，未复制参考网站的代码或现代解读内容。

## 解卦的阅读规则

三钱起卦在浏览器内使用 `crypto.getRandomValues`；每枚钱币正面记 3、反面记 2，独立等概率，合计 6／7／8／9 的概率分别为 1／8、3／8、3／8、1／8。六爻按自下而上记录；6 为老阴（变阳），9 为老阳（变阴），7、8 不变。这是三钱模拟，与蓍草法的概率不同。

选文参考《易学启蒙》变占规则，出处链接为[黄宗羲《易学象数论·占法》所录启蒙占法](https://zh.wikisource.org/zh-hans/易學象數論/占法)。零变读本卦卦辞；一变读本卦动爻；二变读两动爻、较高者为主；三变并列两卦卦辞；四变读变卦中未变的两爻、较低者为主；五变读变卦唯一未变爻；六变时乾坤读用九／用六，其余读变卦卦辞。**三爻变采用并读的入门简化，未实现「前十卦主贞、后十卦主悔」的细分。** 页面中明确说明此范围；规则不是所有占法的统一标准。

本功能为本地原书导读：问题用于保留情境和自我反思，不接入 AI 或远程推断服务。生活提问为本站学习引导，变卦用于观察变化，不作必然结果的承诺。学习示例不写入卦记。

起卦动画只负责呈现：点击时生成并保存实际结果，单爻约 1.5 秒，连续起六爻依次演示。动画期间防止重复触发，离开页面会停止动画；刷新或返回时仍保留已生成的结果。系统开启「减少动态效果」时直接显示结果。
